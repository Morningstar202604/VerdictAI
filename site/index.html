⬇ 一分钟上手

三种方式任选，Windows / macOS / Linux 均可

方式 A · 免 git

Release 一键下载

下载最新的 VerdictAI.zip，解压后在 backend/ 目录执行两行命令。

$ pip install -r requirements.txt $ python tools/start_all.py
方式 B · 源码

Git 克隆

国内推荐 GitCode，或 GitHub 镜像。

$ git clone https://gitcode.com/badhope/VerdictAI.git $ cd VerdictAI/backend $ pip install -r requirements.txt $ python tools/start_all.py
方式 C · Docker

容器一键部署

生产环境首选，根目录一条命令。

$ docker compose up -d --build

🚀 启动后打开 http://localhost:8787 → 拖入 PDF → 点「开庭审理」→ 看 7 个专家实时辩论
