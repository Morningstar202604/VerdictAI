裁智能探案合议庭 — 全流程

真实卷宗入库 → AI 意图识别 + 分角色分发 → 多专家辩论 → 纠错 → 审判长落槌 → 报告归档。无任何演示数据，全部走真实大模型。

① 落地页 / 案例库

前端加载 /api/cases 案例库列表
前端下拉/卡片选择案件，勾选出庭专家
AI拖拽 / 选择 PDF / Word / TXT → 进入预处理
设置页「案例库」：列表 / 删除 / 生成示例 / 选中

② 卷宗预处理（真实 AI）

AIPyMuPDF 提取 PDF 文本
AI意图识别（intake 模型）
AI思考强度评估 + 总体提示词生成
AI按角色聚焦分派差异化材料
前端动画展示 5 步 + 打字机结果 → 确认开庭

③ 开庭审理（WebSocket）

WS连接 /ws/{session}
WS发送 start{case_id, intent, judge_mode…}
后端run_debate → 构建辩论图
▼

④ 辩论图（每轮循环）

experts_node：出庭专家依次举证质证
实时每专家发言完 → AI 书记员生成合议记录（主张/证据/疑点）→ 推 agent_note
critic_node：纠错官交叉比对，输出矛盾清单
judge_node：审判长收敛判断
未收敛 → 回到 experts（下一轮）
已收敛 → 进入裁决

⑤ 右侧面板（动态记录）

实时合议记录：每个专家一张卡（一句话主张 + 证据标签 + 疑点）
矛盾 · 纠错清单：critic 提取的结构化矛盾
审判长裁决书：真相推定 / 证据链 / 存疑点 / 建议
人类可中途「插话」介入下一轮
▼

⑥ 落槌 / 裁决

judge_mode=ai：AI 审判长直接出裁决书
judge_mode=human：暂停，等待人类法官落槌（采纳/改写）
WS推送 verdict → 前端渲染裁决书

⑦ 审判报告

点击「下载审判报告」生成完整 HTML
含：概要 / 人员 / 证据 / 笔录 / 矛盾 / 裁决
案件自动保留在案例库，可复跑或删除
设计说明：界面采用「朱批」视觉体系——象牙宣纸底、藏青正文、鎏金点缀、朱砂落印。裁决书生成时印章以「落章」动画盖下，象征 AI 辅助意见定稿；夜审模式（🌙）对应夜间阅卷场景。
实时记录：右侧面板在每个专家发言结束时即收到 agent_note 提炼卡，辩论过程中持续更新，而非等一轮结束才有内容。
最终裁决权：AI 只做辅助分析，人类法官始终握有最终裁决权（judge_mode=human 时辩论末自动暂停等待落槌）。
