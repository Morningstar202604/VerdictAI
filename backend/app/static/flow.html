多智能体法律探案审判系统 — 全流程

真实 PDF 入库 → AI 意图识别 + 分角色分发 → 多专家辩论 → 纠错 → 审判长裁决 → 报告。无任何演示数据，全部走真实大模型。

① 落地页 / 案例库

前端加载 /api/cases 案例库列表
前端下拉/卡片选择案件，勾选出庭专家
AI拖拽 / 选择 PDF → 进入预处理
设置页「案例库」：列表 / 删除 / 生成示例 / 选中

② 卷宗预处理（真实 AI）

AIPyMuPDF 提取 PDF 文本
AI意图识别（intake 模型：step-3.7-flash）
AI思考强度评估 + 总体提示词生成
AI按角色聚焦分派 8 份差异化材料
前端动画展示 5 步 + 打字机结果 → 确认开庭

③ 开庭审理（WebSocket）

WS连接 /ws/{session}
WS发送 start{case_id, intent, judge_mode…}
后端run_debate → 构建 LangGraph
▼

④ 辩论图（每轮循环）

experts_node：8 专家依次举证质证
实时每专家发言完 → AI 书记员生成合议记录（主张/证据/疑点）→ 推 agent_note
critic_node：纠错官交叉比对，输出矛盾清单
judge_node：审判长收敛判断
未收敛 → 回到 experts（下一轮）
已收敛 → 进入裁决

⑤ 右侧面板（动态记录）

实时合议记录：每个专家一张卡（一句话主张 + 证据标签 + 疑点）
矛盾·纠错清单：critic 提取的结构化矛盾
审判长裁决书：真相推定 / 证据链 / 存疑点 / 建议
人类可中途「插话」介入下一轮
▼

⑥ 落槌 / 裁决

judge_mode=ai：AI 审判长直接出裁决书
judge_mode=human：暂停，等待人类法官落槌（采纳/改写）
WS推送 verdict → 前端渲染裁决书

⑦ 审判报告

点击「下载审判报告」生成完整 HTML
含：概要 / 人员 / 证据 / 笔录 / 矛盾 / 裁决
案件自动保留在案例库，可复跑或删除
为什么之前"像是 demo"：旧代码里落地页默认硬加载 case_001 这个内置示例，且上传后若未点「确认并准备开庭」就不会切换。现已：① 删除 case_001；② 所有案件来自案例库；③ 上传即入库并自动选中；④ 设置页可直接管理（删除/生成/选中）。
实时记录为什么之前是空的：旧版右侧只在每轮结束的 critic_end 才有内容。现已新增 agent_note 事件——每个专家发言结束，后台用 intake 模型异步提炼一张「合议记录」卡推到右侧，辩论过程中持续更新。
