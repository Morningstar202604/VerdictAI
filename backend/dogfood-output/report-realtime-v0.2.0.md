## 本轮发现并修复的问题

### P0 - 上传案件必现崩溃（已修复）
- **位置**: [main.py](file:///workspace/VerdictAI/backend/app/main.py)
- **症状**: `POST /api/cases/upload` → HTTP 500 `NameError: name '_re' is not defined`
- **根因**: `upload_case` 内使用 `_re.sub` 做标题去重，但 `import re as _re` 只存在于 `generate_case` 的局部作用域，模块级未导入
- **影响**: **核心功能「上传案件」100% 必现崩溃**，用户只要上传文件就会 500
- **修复**: 模块级 `import re`，统一 `re` 引用
- **验证**: ✅ 上传 PDF 成功 → AI 解析出 5 人 / 9 证据 / 9 时间线 / 5 法条 / 3 图表

### P1 - 思维链模型判决 JSON 被截断（已修复）
- **位置**: [llm.py](file:///workspace/VerdictAI/backend/app/models/llm.py), [config.py](file:///workspace/VerdictAI/backend/app/config.py)
- **症状**: 辩论正常，但判决始终为「解析失败，请重试或调整模型」
- **根因**: `原生思维链/gemini` 类模型把大量推理写入 `reasoning_content`，`ChatOpenAI` 未设置 `max_tokens` → 平台默认上限很小 → `content` 中 JSON 被截断 → `_extract_json` 失败
- **影响**: 高思考强度模型下判决质量归零
- **修复**: 新增 `LLM_MAX_TOKENS` 配置（默认 8000），`get_llm` 显式传入
- **验证**: ✅ 修复后判决完整生成：真相推定 + 5 条证据链 + 5 条疑点 + 5 条下一步，内容完全基于卷宗真实细节

### P2 - 前端无法连接后端 API（已修复部署配置）
- **位置**: [vite.config.ts](file:///workspace/VerdictAI/frontend/vite.config.ts)
- **症状**: React 前端在 5173 端口运行时，`/api/*` 请求落到 vite 自身返回 HTML（404 语义），WS 也无法连接
- **根因**: vite dev server 未配置代理，前端与后端跨端口无法通信
- **修复**: 添加 `/api` `/ws` `/static` `/sandbox` 四路代理 → 8787
- **验证**: ✅ 前端经代理获取 roles/cases/settings 全部 200；WS 代理握手成功；静态图表 200

### 外部限制（非程序 Bug，已自动容错）
- **API 限流**: 供应商 1 分钟最多 5 次请求（失败也计数），每次响应约 35 秒
- **表现**: 辩论中出现 429，系统自动指数退避重试（1.5s→3s→6s），部分专家降级为空分析，辩论不崩溃
- **影响**: 单场辩论耗时数倍拉长（2 轮约 11 分钟），属供应商配额问题
